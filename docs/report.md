# Звіт до лабораторної роботи №6

1. **Що змінилося у виводі `git status` після `git add`?**
   Файл перейшов із червоної секції невідстежуваних файлів (Untracked files) у зелену зону 
   індексу (Changes to be committed), тобто став підготовленим до збереження у commit.

2. **Що показує `git diff`?**
   Команда показує построкову різницю між поточними незбереженими змінами у файлі та 
   останнім збереженим commit-ом (додані рядки позначаються зеленим кольором зі знаком
    `+`, а видалені — червоним зі знаком `-`).

3. **Чим відрізняється `git switch main` від `git merge`?**
   Команда `git switch main` просто перемикає робочу папку на гілку `main`, а `git merge`
    об'єднує історію та переносить зміни з іншої гілки в поточну.

4. **Чому виник конфлікт і як ти його розв'язав?**
   Конфлікт виник через те, що в обох гілках (`main` та `ukr-title`) було по-різному
   змінено один і той самий рядок заголовка `<h1>` у файлі `index.html`. Я розв'язав його
   вручну: видалив службові маркери конфлікту, об'єднав текст заголовка в один рядок, після 
   чого виконав `git add` і `git commit`.
